# Roadmap

1. Flask foundation: factory, REST endpoints, SQLAlchemy, Orbit Wars adapter, Redis/RQ job option, tests, CI. Validate with real Kaggle exports.
2. Reliability: PostgreSQL, Alembic migrations, worker retries, indexes, documented OpenAPI contract, fixtures.
3. Visualization: Jinja/HTMX dashboard, Chart.js score/production timelines, processing status and failures.
4. Experiment science: opponent/seed/slot metadata, paired-match comparisons, uncertainty/effect sizes, replay evidence viewer.
5. Portfolio release: Docker Compose, auth, live demo, profiling and performance benchmarks, polished documentation.

Each stage should deliver a testable vertical slice before the next stage starts.
